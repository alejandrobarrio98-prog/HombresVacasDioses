# Carpeta de imágenes

Aquí van las fotografías reales de las obras: portadas de libros,
pinturas y fotografías enmarcadas, y el retrato del autor.

Recomendaciones:

- Formatos: `.jpg` para fotos, `.png` para portadas o imágenes con
  fondos planos.
- Tamaño sugerido: entre **1200 y 1600 píxeles** en el lado más
  largo. Suficiente para verse bien y liviano para cargar rápido.
- Nombres de archivo: cortos, en minúscula, sin acentos ni espacios.
  Usa guiones en lugar de espacios.

Ejemplos de buenos nombres:

- `vaca-mediodia.jpg`
- `libro-de-hombres-vacas-dioses.jpg`
- `retrato-sergio.jpg`

Una vez pegada la imagen aquí, revisa `LEEME.md` en la carpeta
principal para ver cómo enlazarla desde cada página.
